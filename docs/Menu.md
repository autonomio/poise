# Menu and Settings

The burger at the top right opens a surface attached to the button. Choose
Analytics, Logging, or a destination under Settings: General, Navigation, Models, Accounts,
Publishing or Typography. Service administrators also see Admin. Analytics and Logging
are views of their own: choosing it closes the menu and
replaces the page, and the menu marks it as the current page while it shows
(see [Analytics](Analytics.md) and [Logging](Logging.md)). There is no second tab strip inside
Settings. Back returns to the menu on the same surface. The burger becomes
the single close button while the menu or a panel is open; clicking it or
pressing Escape closes the surface. Escape inside an account terminal belongs
to the running program.
If Writer mode is enabled with a panel open, the single close button remains
visible until the surface is dismissed.

Navigation chooses which views appear above Settings in the menu and in the
top bar. Each view has an independent checkbox for each surface: show it in
either, both, or neither. Changes apply immediately and stay in this browser,
including across reloads and other open tabs. Reset navigation restores the
original layout: Analytics and Logging in the menu; Current, Swarm, Chat,
Archive, Behaviors, Snippets and Editor in the top bar. Settings and the release
information remain accessible. Hiding the current view's shortcuts leaves
that view open. Selecting Analytics on either surface opens Today.

General holds GitHub identities, accounts to follow, time, notifications,
chat defaults and theme. Models holds named configurations and model choices.
Changes that need saving have a Save button at the bottom. Accounts separates
AI provider sign-ins from GitHub sign-ins, with Poise Link in service mode and
a workspace terminal. Publishing lists the websites the Editor publishes to
(see [Publishing](Publishing.md)). Typography controls fonts, spacing and density.

Explanations appear after half a second over the relevant label, heading,
value or action, and on keyboard focus. Errors, account state and pairing
instructions remain visible.

The frame follows the burger across views and viewport sizes. Reduced-motion
preferences remove its animations. Existing account, pairing and admin links
open their destination directly.
