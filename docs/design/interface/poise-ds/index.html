Universal reference

Every control and display carries a key into one registry. The tooltip and the full reference read the same entry.

Tooltip after 0.5 s on pointer rest, keyboard focus or a long press. It names the element, says what it is, and links to the full reference; you can move onto it.

Full reference dims everything but the element, keeps it lit and wired to a card that answers: what it is, what it does, what the current value means, other values, what it affects, when a change applies, what stays unchanged, how the result shows, where the information comes from, and why it is unavailable.

Never in the way. The card moves aside rather than cover the element, opening it presses nothing, and Esc returns focus and scroll to where you were.
